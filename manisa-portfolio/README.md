# Portofolio Manisa Fani Rahmasari

Website portofolio berbahasa Indonesia dengan fokus Administration & Customer Service.

## Isi folder
- `index.html` — halaman utama website.
- `assets/` — foto wisuda dan dokumentasi pengalaman magang BPJS Kesehatan KC Sleman serta BPRS BDS.

## Publikasi dengan GitHub Pages
1. Buat repository bernama `manisafani.github.io`.
2. Unggah **isi folder** `manisa-portfolio` (file `index.html` dan folder `assets`) langsung ke root repository.
3. Buka Settings → Pages.
4. Pilih Source `Deploy from a branch`, Branch `main`, Folder `/(root)`, lalu Save.
5. Tunggu proses deployment selesai. Website akan tersedia di `https://manisafani.github.io`.

Pastikan `index.html` berada langsung di root repository, bukan di dalam subfolder.
